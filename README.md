# مستودع مشروع: iron-plus (iron plus)
## تطبيق أندرويد متكامل (Android 15) وتطبيق آيفون متكامل (iPhone iOS 18) — جاهز لمنصة Cloudflare Pages

نظام متكامل لإدارة الجيم والاشتراكات وبوابة الباركود والمدفوعات يعمل كتطبيق أندرويد أصيل (Material Design 3) وتطبيق آيفون أصيل (iOS 18 Cupertino & Dynamic Island).

## إعدادات الربط مع منصة Cloudflare Pages
- **Repository Name**: `iron-plus` (`iron plus`)
- **Production branch**: `main`
- **Framework preset**: `Vite`
- **Build command**: `npm run build`
- **Build output directory**: `dist`
